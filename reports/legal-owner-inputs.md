# Údaje, které musí dodat provozovatel

Datum: 2026-11-05. Aplikace tyhle údaje nemá a sama je nedoplňuje. Dokud tu zůstanou prázdné, právní stránky nejsou hotové a nejsou právně schválené.

Autor projektu chce být provozovatelem a na stránce Podpoř mě uvádí, že je nezletilý. Samostatná výdělečná činnost z toho nevyplývá. Potvrzené podnikatelské oprávnění ani schválený komerční provoz v projektu nejsou.

## Identita

- [ ] Jméno nebo název provozovatele
- [ ] Adresa
- [ ] IČO, pokud ho provozovatel má
- [ ] Kontaktní e-mail, který se smí zveřejnit
- [ ] Právní status projektu
- [ ] Souhlas zákonného zástupce, pokud má být provozovatel nezletilý a činnost to vyžaduje
- [ ] Podnikatelské oprávnění, pokud má jít o výdělečnou činnost

V kódu odesílání e-mailu podnikům je natvrdo osobní adresa. Není to zveřejněný kontakt správce. Do právních stránek se nekopíruje, dokud ji provozovatel sám neschválí.

## Zpracování

- [ ] Právní základ pro účet, oblíbené, recenze, hlášení recenze a žádost podniku
- [ ] Doba uložení účtu
- [ ] Doba uložení recenzí po smazání nebo po zrušení účtu
- [ ] Doba uložení hlášení recenze
- [ ] Doba uložení žádosti podniku, fotografie a otisku adresy odesílatele
- [ ] Doba uložení e-mailů odeslaných přes nastavenou e-mailovou službu
- [ ] Kdo vyřizuje žádost o přístup, opravu a výmaz a jakou cestou
- [ ] Postup, když web výmaz účtu tlačítkem neumí
- [ ] Zda se mají písma načítat z Google, nebo se soubory uloží u CheapEats
- [ ] Oblast, ve které běží databáze účtů
- [ ] Jestli e-mailová služba a hosting zpracovávají údaje mimo EU nebo EHP
- [ ] Seznam zpracovatelů, který provozovatel potvrdí

## Provoz a peníze

- [ ] Rozhodné právo a způsob řešení sporů
- [ ] Rozsah odpovědnosti za menu, provoz restaurace a nabídky třetích stran
- [ ] Kdo si smí založit účet
- [ ] Jestli se dobrovolná podpora vůbec zapne, a pokud ano, ověřený příjemce, podmínky platební služby a souhlas zákonného zástupce
- [ ] Jestli se ceník pro podniky vůbec začne prodávat
- [ ] Smlouva, fakturace a označení sponzorovaného výsledku, než se první reklama zapne

## Co se nesmí doplnit odhadem

Jméno, adresa, IČO, e-mail, právní základ, retenční lhůta a tvrzení, že text už zkontroloval právník.
